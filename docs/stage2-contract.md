# Runner and release status

Stage 2 adds production planning, durable create-only journal/seal publication,
bounded capture and Linux foreground collection. See [the Linux contract](linux-runner.md)
for its explicit observed admission/immutable-commit revision. The original
Stage 1 formats and exact integer calculation remain the evidence boundary.

The alpha includes real original harmless helper tests, publication fault cuts,
interruption prefixes, unrelated sentinel survival and plan/run/analyze/verify
round trips. Synthetic teaching examples remain explicitly synthetic. Neither
consistent bytes nor method labels authenticate actual randomization or timing.

Remaining release gates: independently review the final exact candidate; qualify
additional Python/interpreter/platform combinations; perform clean install tests
when authorized (extracted wheel/sdist execution is a different test); retain
measured resource evidence for every supported maximum. Linux collection and
portable analyzer validation are distinct capabilities. No network filesystem,
escaped process containment, benchmark-program resource sandbox, hardware
reproducibility or hostile same-user security boundary is promised.

Publication, package reservation, repository creation, release tags and uploads
are separate decisions. This source tree performs none of them.
